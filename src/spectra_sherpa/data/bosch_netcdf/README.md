# BOSCH lookup dictionaries

Unmodified `Dictionary_OES.nc` and `Dictionary_process.nc` from
[Zenodo 17122442](https://doi.org/10.5281/zenodo.17122442), CC BY 4.0.
See the package NOTICE.md for the full title, authors and attribution.
The reader pins each file's SHA-256 and uses it offline. Raw daily OES files
and process measurements are downloaded separately by the user.

`Lot_status.xlsx` is the unmodified source lot table. `experiment_context.json` normalizes its dates and conditioning settings alongside the README protocol. Lot assignments require a matching published source checksum; unknown sources retain reference protocol only.
