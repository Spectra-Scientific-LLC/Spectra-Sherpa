# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| Latest  | Yes                |
| Older   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability in SpectraSherpa, please report it responsibly.

**Email**: security@spectrascientific.ai

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (optional)

## Scope

This policy covers the open-source **SpectraSherpa** core (this repository). The proprietary `spectra-server` package is not in scope for public reports.

## Response Timeline

- **Acknowledgement**: Within 3 business days
- **Initial assessment**: Within 7 business days
- **Fix or mitigation**: Depends on severity, but we aim for 30 days for critical issues

## Disclosure

We follow coordinated disclosure. Please do not publicly disclose the vulnerability until we have had a chance to address it.
