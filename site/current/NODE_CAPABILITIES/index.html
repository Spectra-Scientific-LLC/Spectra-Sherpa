🔍 How to Find Nodes in Frontend

  1. By Category: Nodes are organized in collapsible sections:
  2. Data (4 nodes)
  3. Preprocessing (21 nodes)
  4. Modeling (8 nodes)
  5. Classification (3 nodes)
  6. Analysis (1 node)
  7. Synthesis (3 nodes)

  8. Output (4 nodes)

  9. By Search: Use the search bar at top of Node Library panel to filter by:

  10. Node label (e.g., "PCA", "Baseline")
  11. Description text (e.g., "normalization", "derivative")

  12. Node type (e.g., "model.pca")

  13. Common Algorithms:

  14. MCR-ALS: Look under "Modeling" → "MCR-ALS"
  15. PLS-DA: Look under "Classification" → "PLS-DA"
  16. Outlier Detection: Look under "Modeling" → "Outlier Detection"
  17. EMSC: Look under "Preprocessing" → "EMSC"
  18. OSC: Look under "Preprocessing" → "OSC Filter"

📝 Notes

  • All nodes are fully functional with parameter validation
  • Some advanced nodes (MCR-ALS, SIMCA) require specific input formats
  • Nodes support both single spectra and multi-spectrum datasets
  • Most preprocessing nodes can be chained for complex workflows
  • All modeling nodes return serializable results (no raw sklearn/numpy objects)

If you still cannot find a specific node, please: 1. Restart the backend server to ensure latest node registry 2. Clear browser cache and reload frontend 3. Check browser console for API errors 4. Verify backend is running: curl http://localhost:8000/api/v1/workflows/nodes/library
