# Contributors

Thanks to everyone who has contributed to Spectra Sherpa.

This file is **append-only and machine-maintained** by the release
tooling: external contributors whose changes ship in a release are added
here automatically and are never removed. Contributors are also credited
via `Co-authored-by` trailers on release commits and named in the
`CHANGELOG.md` "Thanks" section for the release their work shipped in.

If you contributed and do not see your name after the next release,
please open an issue — attribution is a release gate, not an
afterthought, and a missing name is a bug.
