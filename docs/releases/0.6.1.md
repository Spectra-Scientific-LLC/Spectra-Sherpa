# SpectraSherpa 0.6.1

Source version **0.6.1**, dated 2026-10-08. This is a validation candidate;
these notes do not announce a PyPI package, public source tag or signed desktop
installer. The published 0.6.0 installation instructions remain applicable
until a separate publication is completed.

## Saved-run context

The Workbench preserves the selected saved run and workflow when opening
hosted Advisor conversations. Navigation and query changes retain the intended
scope; changing the selected run or project clears stale context.

On deployments with managed Advisor enabled, explanations can retrieve owned
retained results and calculate bounded statistics without rerunning a workflow.
Saved facts are context, not a substitute for retrieving the evidence needed
to answer a question. Unavailable or reduced retained output remains an explicit
limitation. Managed Advisor and optimization are hosted capabilities, not new
features of the local OSS package.

Scientific interpretation distinguishes training, development cross-validation
and held-out results. Comparing response ranges does not establish spectral
coverage, independence or generalization.

## Report and audit navigation

Report has Setup and Preview only. The ISO 17025 evidence-pack rehearsal is an
operator runbook in the commercial server's audit documentation, not a
chemometric method or accreditation claim on the Report page. The OSS audit
emitter, retained provenance, and locally enabled audit query remain in place.
The Demo interface does not offer audit actions; server-governed chain and
evidence-pack endpoints remain unentitled. Pro audit/evidence-pack entitlement is a
separate product decision; this release does not grant it.

## Validation boundary

The version update does not change algorithms, dependencies or wire-schema
versions. Public package publication and desktop qualification are separate
from hosted validation. See the [0.6.0 release notes](0.6.0.md) for the existing
scientific and installation baseline.
