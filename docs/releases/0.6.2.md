Source version **0.6.2**. The availability of a public tag, PyPI package,
desktop installer and Demo production deployment must be checked separately;
none follows from this source document alone.

## Scientific workbench

PCA and PLS model views link components, scores, loadings, sample review and
fitted-variable contributions. Component-selection displays the validation
design that was actually executed. Regression and classification use distinct
metrics; a classifier without valid cross-validation no longer presents its
calibration accuracy as a ranked validation result.

Saved models can be compared within a project. PLS-DA rows name their target
and show verified classification validation where available. The comparison
does not borrow a held-out score from another model in a branched workflow,
and it does not translate classification accuracy into RMSE or R².

Single and batch applications carry model-bound applicability evidence where
supported. Reference-value method, units and uncertainty context remain
visible when recorded; unknown precision is not invented. PLS-DA response
permutation provides an additional, reproducible check against random labels.

Development cross-validation is not independent confirmation. A passing global
applicability screen does not prove local calibration support or prediction
accuracy, and a permutation result does not replace a held-out test.

## Managed Advisor

On entitled hosted deployments, Sherpa Advisor can interpret cited, retained
diagnostic evidence and answer follow-up questions within its disclosure
boundary. The local OSS Workbench retains the numerical diagnostic views;
managed Advisor and optimization remain hosted capabilities.
