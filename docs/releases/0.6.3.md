# SpectraSherpa 0.6.3

Source version **0.6.3**. The availability of a public tag, PyPI package,
desktop installer and Demo production deployment must be checked separately;
none follows from this source document alone.

## What 0.6.3 contains

0.6.1 and 0.6.2 were not tagged or uploaded to PyPI. 0.6.3 is the first
tagged release since 0.6.0 and contains the [0.6.1](0.6.1.md) and
[0.6.2](0.6.2.md) changes, including explicit, acknowledged application of
eligible saved 0.6.0 models. It adds no application features beyond them.

## Dependencies

Runtime dependency ranges widen for FastAPI, Starlette, Uvicorn and asyncpg,
and the lock moves to SQLAlchemy 2.1, Alembic 1.20 and Pydantic 2.14 among
other patch and minor updates. The frontend takes patch and minor updates,
including KaTeX 0.19. The desktop build requires PyInstaller 6.22.3 or later.
See the CHANGELOG for the list.

## Platform qualification

Public CI now runs the backend tests, with the default and PostgreSQL
profiles, and the desktop shell tests on Linux, macOS and Windows. It runs for
every pull request, every push to `main` and once a week. A release is cut only
from a commit whose public CI is green on all three platforms.

## Saved-model compatibility

A new check fits models with each reviewed earlier release, upgrades, and
applies them with the new code. A second mode fits and applies models with the
new code alone. A model that stops applying fails the check unless the break
is a recorded decision. Models that 0.6.0 fitted on tabular (non-spectral)
data recorded no column identity; they cannot be verified and must be refit.

## Qualification boundary

This document does not itself record CI or release results. Public OSS
publication, PyPI upload, Demo production promotion and desktop packaging are
separate decisions.
