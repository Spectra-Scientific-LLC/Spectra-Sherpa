# Eigenvector Research Example Datasets

SpectraSherpa uses the publicly available example datasets hosted by
[Eigenvector Research](https://eigenvector.com/resources/data-sets/) in its
reference catalog, onboarding, and workflow examples. We thank Eigenvector
Research and the original contributors for making these resources available
to the chemometrics community.

The catalog includes:

- Diesel NIR calibration data
- Corn NIR instrument-standardization data
- CGL NIR data
- IDRC 2002 NIR Shootout data
- SEMATECH/Texas Instruments metal-etch OES and process-monitoring data

These are excellent datasets for PCA, PLS calibration, classification, process monitoring, calibration transfer, and workflow export checks. They let scientists explore realistic spectra, targets, missing values, and instrument differences while learning the tools.

## User-Acquired Import Model

SpectraSherpa catalogs these datasets but does **not** redistribute the raw Eigenvector files in the Python wheel or source distribution.

The **Reference Datasets** card links to the provider. Download the file from
Eigenvector Research, then choose **Import downloaded file**. SpectraSherpa checks that it matches the reference dataset before
importing it.

For your own datasets, use the normal file import in Local OSS, desktop,
Subscription Cloud, or Enterprise Hybrid.
