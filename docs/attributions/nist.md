# NIST

SpectraSherpa can use NIST reference data for library comparison and synthetic infrared workflows. NIST is a scientific data foundation, not a SpectraSherpa-owned dataset.

## Sources

- [NIST Chemistry WebBook](https://webbook.nist.gov/)
- NIST Quantitative Infrared Database

## Citation

Cite NIST when NIST spectra or NIST-derived synthetic datasets are used in reports, validation records, publications, or customer-facing analysis.

The NIST Chemistry WebBook provides access to chemical and physical property data, including spectral properties, for well-defined chemical species. SpectraSherpa provides application workflows around those public scientific resources; it does not own, replace, or relicense NIST data.
