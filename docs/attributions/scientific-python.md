# Scientific Python

SpectraSherpa draws on the scientific Python community for numerical computing,
chemometric modeling, and data handling. We gratefully acknowledge the authors
and maintainers of these packages.

| Package | Role in SpectraSherpa | Citation guidance |
| --- | --- | --- |
| **scikit-learn** | Estimators and tools for regression, classification, decomposition, clustering, and model evaluation | [About and citing scikit-learn](https://scikit-learn.org/stable/about.html#citing-scikit-learn) |
| **NumPy** | Spectral matrices, array operations, and numerical linear algebra | [Citing NumPy](https://numpy.org/citing-numpy/) |
| **SciPy** | Scientific algorithms, optimization, signal processing, and statistics | [Citing SciPy](https://scipy.org/citing-scipy/) |
| **pandas** | Tabular data, sample metadata, and data preparation | [Citing pandas](https://pandas.pydata.org/about/citing.html) |
| **SpectroChemPy** | Optional EFA, MCR-ALS, and SIMPLISMA algorithms | [SpectroChemPy attribution and supported version](spectrochempy.md) |

## Credit the methods behind your results

When a package contributes materially to an analysis, cite its recommended
publication and record the software version used. For a particular scientific
method, also credit the original method paper where appropriate; package
attribution complements that scientific citation.

The upstream citation pages provide the authoritative references and citation
formats. Record versions from the environment that produced the saved result,
rather than substituting the newest available release.

## Data and reference sources

Scientific data deserve their own credit. See [Eigenvector Research](eigenvector.md)
for the publicly available example datasets used in onboarding and workflow
examples, [NIST](nist.md) for spectral references, and [HITRAN/HAPI](hitran.md)
for gas-phase reference data and synthesis. See the
[attributions overview](index.md) for reader and instrument-file contributions.
