# NIST Library

The **Library** module provides direct access to the NIST WebBook, allowing you to search for and download standard reference spectra.

## Searching

1.  Navigate to **Library** in the sidebar.
2.  Enter a compound name (e.g., "Ethanol", "Limonene") in the **Search** tab.
3.  Results display the Compound Name, CAS Number, and NIST ID.

## Downloading

*   **Standard**: Click **Download** for standard resolution.
*   **High-Res**: Click **High-Res** (if available) for detailed spectral features.
*   Downloads are processed in the background.

## Viewing & Using Spectra

*   **Browse**: View all downloaded spectra in the **Library** tab.
*   **Inspect**: Click an entry to see its interactive plot and metadata.
*   **Synthesis**: Select spectra and click **Add to Builder** to use them in the Synthesis module.
